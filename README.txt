MOHAMMAD SAM GAME

Upload the contents of this folder to the root of your GitHub repository.
Then open Actions and run "Build MOHAMMAD SAM GAME APK".
When it finishes, download the MOHAMMAD-SAM-GAME-APK artifact, extract it,
and install the APK on your Android phone.

Controls: hold left third to move left, middle third to move right,
tap right third to jump. Collect coins, avoid enemies, and reach the flag.
The character is currently a simple placeholder sprite; the uploaded reference
photo has not been integrated into the game yet.
